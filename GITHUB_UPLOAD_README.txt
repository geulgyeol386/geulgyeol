GitHub 업로드용 안전본

현재 오류 원인:
- 배포 주소는 /story/index.html을 찾고 있지만 GitHub 저장소에는 story 폴더가 올라가지 않았습니다.
- GitHub 웹 업로드에서 폴더 전체가 누락되면 서버는 '파일을 찾을 수 없습니다'를 표시합니다.

이번 안전본:
- Story 페이지를 저장소 루트의 story.html로 변경했습니다.
- 모든 Story 이미지는 기존 images 폴더 안에 story_ 접두어로 저장했습니다.
- 메인 페이지의 Story 링크도 story.html로 연결했습니다.
- 이제 story 폴더 없이도 작동합니다.
