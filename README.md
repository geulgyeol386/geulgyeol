# 글결 Ver8.0

Ver7.12의 운영 기능을 유지하면서 관리자 첫 화면을 운영 대시보드로 개선한 안정화 버전입니다.

## 새 기능
- 오늘 새 주문, 처리 대기, 제작 진행, 이번 달 수입
- 지금 확인할 주문
- 최근 주문
- 작업 단계별 현황
- 새로고침과 마지막 갱신 시각
- Railway 환경변수 백업 양식
- 정식 배포 점검표

# 글결 Ver7.12 운영 편의 개선 버전

## Railway 운영
필수 환경변수:
- `ADMIN_USER` : 관리자 아이디
- `ADMIN_PASSWORD` : 관리자 비밀번호
- `DATABASE_URL` : Postgres 서비스의 `DATABASE_URL` 참조값

`DATABASE_URL`이 설정되면 주문은 PostgreSQL에 영구 저장됩니다.
Railway 재배포 후에도 주문 데이터가 유지됩니다.

## 데이터베이스
서버 시작 시 `orders` 테이블이 자동 생성됩니다. Railway 화면에서 테이블을 직접 만들 필요가 없습니다.

기존 `data/orders.json`에 주문 데이터가 있고 PostgreSQL이 비어 있으면 최초 연결 시 자동으로 이관합니다.

## 로컬 실행
Node.js 설치 후:

```bash
npm install
npm start
```

브라우저에서 `http://127.0.0.1:3210`으로 접속합니다.
로컬에서 `DATABASE_URL`을 설정하지 않으면 기존 `data/orders.json` 저장 방식을 사용합니다.

## 주문번호
신규 주문은 `2026-001`, `2026-002`처럼 연도-일련번호로 자동 발급됩니다.

## Ver7.09 AI 맞춤 문구 추천

Railway Variables에 아래 값을 추가합니다.

- `OPENAI_API_KEY`: OpenAI API 키
- `OPENAI_MODEL`: 선택 사항. 기본값 `gpt-5.6-luna`

AI 추천 시 고객의 이름, 전화번호, 이메일은 AI 서비스로 보내지 않습니다. 사연, 전하는 대상, 글씨 분위기, 희망 문구 길이만 전송합니다.

## Ver7.12 주문 알림·메모·진행 이력·백업
- 새 주문 접수 시 외부 알림 서비스로 전달하는 웹훅 지원
- 관리자 내부 메모 유지
- 상태, 입금, 완성 사진, 송장번호 변경 이력 자동 기록
- 관리자 화면에서 서버 기준 전체 주문 백업 JSON 다운로드

### 주문 알림 설정
Railway Variables에 다음 값을 등록합니다.
- `ORDER_NOTIFICATION_WEBHOOK_URL`: 카카오톡 발송을 연결한 Make, Zapier, n8n, Cloudflare Worker 등의 웹훅 주소
- `ORDER_NOTIFICATION_WEBHOOK_SECRET`: 선택 사항. 웹훅 검증용 비밀값
- `PUBLIC_BASE_URL`: 관리자 링크에 사용할 주소. 기본값 `https://www.ai-seoye.com`

웹훅을 등록하지 않아도 주문 접수는 정상 작동합니다. 카카오 알림톡은 별도 사업자·템플릿 승인과 발송 서비스 연결이 필요하므로, Ver7.12는 승인된 발송 서비스와 안전하게 연결할 수 있는 구조로 제공합니다.


## Ver8.1.1 문구 작성 방식
고객은 주문서에서 `직접 작성` 또는 `AI와 함께 문구 만들기`를 먼저 선택합니다. AI 방식은 GPT 기반 5개 후보 생성과 반복 다듬기 흐름으로 연결됩니다.

## Ver8.2 배포 전 확인

1. Railway Variables에 `OPENAI_API_KEY`를 등록합니다.
2. 필요하면 `OPENAI_MODEL`을 지정합니다. 미지정 시 서버 기본 모델을 사용합니다.
3. 배포 후 홈페이지의 AI 영역에서 `AI 연결 준비가 완료되었습니다.` 문구를 확인합니다.
4. 테스트 주문 1건을 접수하고 관리자 화면에서 AI 작성 이력이 표시되는지 확인합니다.
5. 이번 버전에는 카카오톡 주문 알림이 포함되지 않습니다.


## Ver8.3 텔레그램 주문 알림
관리자 페이지의 **알림 설정**에서 봇 토큰을 입력하고 ‘연결 및 Chat ID 찾기’를 누릅니다. 연결 전 텔레그램의 글결알림 봇 대화방에 `/start` 또는 아무 메시지를 먼저 보내야 합니다. 새 주문 접수 시 텔레그램으로 즉시 알림이 전송됩니다.

선택적으로 Railway Variables에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 등록할 수 있으며 이 값이 관리자 화면 저장값보다 우선합니다.
