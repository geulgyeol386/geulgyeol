글결 Ver8.2 Railway 실제 업로드 체크리스트

[필수 환경변수]
- DATABASE_URL : Railway PostgreSQL 연결값
- ADMIN_PASSWORD : 관리자 비밀번호
- OPENAI_API_KEY : AI 문구 생성용 OpenAI API 키

[선택 환경변수]
- ADMIN_USER : 미지정 시 admin
- OPENAI_MODEL : 서버 기본값 사용 가능
- PUBLIC_BASE_URL : 실제 서비스 주소

[배포 후 확인]
1. /healthz 응답 확인
2. 홈페이지 주문서에서 직접 작성 방식 확인
3. AI와 함께 작성 선택 후 연결 완료 문구 확인
4. AI 문구 5개 생성 → 후보 선택 → 다듬기 3개 생성 확인
5. 테스트 주문 접수
6. 관리자 주문 상세에서 생성/다듬기 횟수, 문체, 강조 내용 확인
7. 테스트 주문 삭제

주의: 카카오톡 주문 알림은 Ver8.2 범위에서 제외했습니다.
